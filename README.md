# Bedroom Racers — playable build

**▶ Play: https://dumb-tony.github.io/bedroom-racers-play/**

An arcade racer about toy cars racing across childhood play spaces — a bedroom
rug, a bedside table, a sandbox, and a plastic stunt track up on the furniture.

Keyboard or gamepad. Up to four players on one screen.

## What this repository is

Only the built game: one self-contained HTML file, no dependencies, no network
calls. It exists to give the game a public URL.

**The source lives elsewhere, in a private repository.** This is the output, not
the project — issues and pull requests here will not reach the code.

## Running it without the link

Download `index.html` and open it. That is the whole game; it works offline.
